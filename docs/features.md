# features

- プレビューを開く（`M-x story-mapping`）
  - `.md`を開いたバッファで使える（拡張子の大文字と小文字は区別しない）
  - `.md`でないファイルや、ファイルのないバッファではエラーになる
  - 描画プログラムがないとエラーになり、パネルは開かない
  - 右のパネルに開き、選択中のウィンドウは元のバッファのまま
  - 保存前の内容（日本語を含む）を表示する
  - ナロイング中でもバッファ全体を描く
  - もう一度呼んでも、バッファもパネルも増えない
- 編集に追従する
  - 編集後の内容に更新される
  - 描画中の編集は、その描画の後に反映される
  - メジャーモードを変えても追従する
  - パネルが閉じている間は描画せず、開き直すと最新の内容を表示する
  - 描画に失敗すると、前の画像を残し、理由をメッセージで伝える
- ズームする
  - 画像の大きさとモードラインの倍率が変わる
  - 20%から200%の範囲に収まり、`0`で100%に戻る
- スクロールする（実際のフレームで確認。バッチのテストでは動かせない）
  - キーとマウスホイールで動く
  - 更新しても位置を保つ
- 閉じる
  - `q`でパネルとバッファが消え、追従も止まる
  - 元のバッファを消すと、プレビューも消える
- SVGを出力する（`M-x story-mapping-export-svg`）
  - 保存前の内容をUTF-8で書く
  - `RET`だけで`.md`の隣の同名の`.svg`に出力する
  - プレビューのバッファからも使える
  - フォルダを指定すると、その中の同名の`.svg`に出力する
  - 同名のファイルがあれば確認し、断ると内容を変えない
  - `.md`でないファイルではエラーになる
- 描画プログラム（`story-mapping-render`）
  - `svg`はSVGを、`png [倍率]`はPNGを標準出力へ書く
  - 正の有限の数でない倍率、未知の引数、UTF-8でない入力では失敗で終わる
  - 失敗のときは標準出力に何も書かず、理由を標準エラーへ書く
  - 空のアウトラインでも画像を書く
